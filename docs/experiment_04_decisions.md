## Opus Stage-0 gate review (2026-10-09; approved by the owner)
| ID | Decision / finding |
|---|---|
| X4-F06 | **X4-F04 explained:** fixing lambda at its true values gives a sandwich SE of sigma2_F* three times the lambda-free value (0.034 vs 0.0114, N = 1000). With J replaced by H the likelihood ordering returns (lambda free 0.0097 >= lambda fixed 0.0079); J/H = 495 for sigma2_F (strong dependence among a learner's 6,216 pairs); 90 % of the per-learner variance of the lambda-fixed sigma2_F score is explained by the 47 log-lambda scores (97.7 % by the 48 difficulty scores). Same composite-likelihood mechanism as X3-F07. A lambda-known oracle would be less precise; it has no practical use and is not run. |
| X4-D07 | **Gate passed** (X4-D03): full rank 113/113 at all four audit points; design SE of sigma2_F* 0.0114-0.0128 at N = 1000 (threshold 0.08); ratio to the 1PL-free SE at lambda == 1 is 1.01. **Stage-1 scope:** R1 build the 2PL estimator, 2PL null bootstrap, warp job, runner, tests, pilot; R2 estimators per dataset 1PL-free and 2PL (no lambda-fixed arm); R3 estimand guard (g and sigma2_F* stored per fit; lambda recovery on centred log lambda); R4 pilot V1/V5 recovery 3 replications and V2 (2PL) / V4 (2PL + 1PL-free) warp 3 datasets per N, at N = 300/1000, timings and certificates; R5 escalate on non-convergence, poor start agreement (> 20 % of fits with < 3/5 starts at the best), projected cost > 150 CPU-h, or > 5 % of log-lambda at bounds. |
