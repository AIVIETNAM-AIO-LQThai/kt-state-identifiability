# Experiment 5: decision and findings log

IDs use the prefix X5. F is a statistical component, never a psychological label; the feedback studied here is "outcome-driven dynamics"
(state dependence), a statistical mechanism.

| X5-D01 | **Question (owner's choice among four candidates):** does outcome-driven dynamics (an error shifts the following latent propensity; Experiment-1 L7, S7) get detected as F by the recommended 2PL pipeline, and can a diagnostic built on the randomised schedule tell it apart? **Scope:** diagnosis, not correction (a joint feedback model needs simulated or indirect inference: later experiment). Generator: Z = -b_q + lambda_q (M0 + alpha H^s + r H^f + F + D) + eps, D_t = kappa sum_{s<t, same session, practice} 1{Y_s = 0} exp(-(t - s)/tau_D), reset at session start; tau_D = tau_F reproduces S7. lambda == 1 in all data. Cells E1 (F, no feedback), E2 (null), E3 (no F, kappa -0.25, tau_D 10), E4 (hardest Stage-0 point still flagged), E5 (F + feedback = S7), E6 (no F, lognormal gains S8n); N {300, 1000}; master seed 20265101; provisional sizes E1/E2 75-100 per N, E3-E5 30, E6 50; hypotheses H5a-H5e provisional, frozen after the pilot; gates G1-G3 as in Experiment 4 (ridge-converged fits count as converged). Not included: correction/joint estimation, adaptive schedules, real data, other misfit types beyond S8n. |
| X5-D02 | **Diagnostic:** generalized (Godambe-adjusted) composite-likelihood score test of eta = 0 for a carry-over term eta * x inside the lambda bracket, at the fitted 2PL B2 model; x = within-item-centred recent error load L = sum_{s<t, same session, practice} exp(-(t - s)/tau_x)(1 - p-hat_{q(s)}), p-hat the observed item success rate; chi2_1, two-sided, alpha 0.05; tau_x fixed a priori in Stage 0 (G0-2). Built from `discrimination_free.twopl.learner_scores` (`wobs`) and `twopl.fisher` with an appended eta column; no extra fits. **Limitations stated in advance:** it detects carry-over from preceding items (outcome- or item-driven), not outcome feedback specifically; valid only when the rest of the model is correct (E6 checks gain misfit); 8 templates limit within-item variation of x (Stage 0 measures power). |
| X5-D03 | **Null reference for the F test:** the per-N q95 of Experiment 4's registered V2 2PL T* distribution (same generator S2 with lambda == 1, same `discrimination_free` fit code), so no new bootstrap replicates; if Stage 0 predicts E[T] < 3 x q95 in a feedback cell, warp bootstrap replicates are added for that cell. |
